Roteiro 1: Escrita Científica em LaTeX (Modelo SBC)

Template oficial para submissão ao Computer on the Beach (COTB)

Passo a Passo no Overleaf

  1. Acesse overleaf.com com sua conta IFSC/Google.
  2. Clique em New Project → Blank Project (ex: Artigo-COTB-2026-GrupoX).
  3. Faça upload dos arquivos sbc-template.sty e sbc.bst.
  4. Configure os nomes da sua dupla e dos orientadores com a filiação IFSC.
  5. Adicione referências acadêmicas no arquivo referencias.bib e cite com \cite{...}.

Boas Práticas do Modelo SBC

  • Tamanho do Artigo: 4 a 6 páginas (artigo curto / extensão).
  • Inserção de Gráficos: Use \includegraphics[width=0.85\linewidth]{grafico.png}.
  • Resumo Bilíngue: Resumo em Português e Abstract em Inglês.
  • Citações Bibliográficas: Mínimo de 5 referências de qualidade (SBC OpenLib, Google Acadêmico, IEEE).

Roteiro 2: Starter Kit Python para Análise de Dados & Gráficos

Geração automatizada de figuras em alta resolução para o Overleaf

O objetivo deste script é ser simples, direto e 100% executável no Google Colab ou no VS Code. Ele calcula média e desvio padrão e salva as figuras em .pdf e .png prontas para o LaTeX.

`analise_experimento.py`
analise_experimento.py Python 3 
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

# 1. Carregamento de dados (ou CSV da pesquisa)
# df = pd.read_csv("dados_coletados.csv")
categorias = ['Portal A', 'Portal B', 'Portal C', 'Portal D', 'Portal E']
pontuacoes = [88.5, 62.0, 94.0, 71.5, 83.0]
desvios    = [3.2, 5.1, 2.0, 4.3, 3.8]

# 2. Tabulação e Estatísticas Descritivas
media_geral = np.mean(pontuacoes)
desvio_geral = np.std(pontuacoes)
print("--- RELATÓRIO ESTATÍSTICO DO EXPERIMENTO ---")
print(f"Média Geral das Amostras: {media_geral:.2f}")
print(f"Desvio Padrão Geral:      {desvio_geral:.2f}")

# 3. Geração do Gráfico para o Paper (Padrão SBC / Alta Resolução)
plt.style.use('seaborn-v0_8-whitegrid' if 'seaborn-v0_8-whitegrid' in plt.style.available else 'default')
fig, ax = plt.subplots(figsize=(7, 4.2), dpi=300)

cores = ['#16a34a', '#0284c7', '#7c3aed', '#d97706', '#0891b2']
barras = ax.bar(categorias, pontuacoes, yerr=desvios, capsize=5, color=cores, alpha=0.9, edgecolor='black', linewidth=0.8)

# Linha de média de referência
ax.axhline(media_geral, color='#dc2626', linestyle='--', linewidth=1.2, label=f'Média Geral ({media_geral:.1f})')

# Rótulos de dados sobre cada barra
for barra in barras:
    yval = barra.get_height()
    ax.text(barra.get_x() + barra.get_width()/2.0, yval + 1.5, f"{yval:.1f}", ha='center', va='bottom', fontsize=9, fontweight='bold')

# Títulos e Eixos
ax.set_title('Diagnóstico Comparativo de Conformidade Web / Dados', fontsize=11, fontweight='bold', pad=12)
ax.set_ylabel('Pontuação Obtida (0 a 100)', fontsize=10, fontweight='bold')
ax.set_xlabel('Portais / Categorias Avaliadas em Garopaba', fontsize=10, fontweight='bold')
ax.set_ylim(0, 110)
ax.legend(loc='upper left', frameon=True)

plt.tight_layout()

# 4. Exportação Automatizada em PDF e PNG para o Overleaf
plt.savefig('grafico_resultado.pdf', format='pdf', bbox_inches='tight')
plt.savefig('grafico_resultado.png', format='png', dpi=300, bbox_inches='tight')
print("-> Gráficos 'grafico_resultado.pdf' e 'grafico_resultado.png' gerados com sucesso!")
plt.show()
