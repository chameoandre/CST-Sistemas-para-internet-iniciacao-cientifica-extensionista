Da Demanda Comunitária ao Paper no Computer on the Beach

Esta unidade curricular integra o Tripé do IFSC (Ensino, Pesquisa e Extensão) com foco prático em Computação. As duplas (ou estudantes individuais) identificam uma necessidade real na sociedade ou no ecossistema web local, realizam coleta/análise de dados com scripts simples em Python e redigem um artigo científico curto (4 a 6 páginas no padrão SBC) para submissão ao evento Computer on the Beach (COTB).

4 Trilhas Práticas de Pesquisa & Extensão

Para garantir acessibilidade e foco no método científico, disponibilizamos 4 eixos temáticos prontos. Cada grupo escolhe a trilha que mais se alinha aos seus interesses. O Python atuará apenas como ferramenta leve de análise de dados (15 a 30 linhas de código no Google Colab/VS Code).

Trilha 1 Dados Públicos

Dados Abertos e Impacto Regional

Investigar dados abertos sobre turismo, educação, saúde ou meio ambiente na região de Garopaba, Imbituba e litoral catarinense para extrair padrões e subsidiar melhorias na comunidade.

💡 Exemplo de Título para o COTB: "Análise de Dados Abertos sobre a Dinâmica Socioeconômica e Ambiental de Garopaba/SC: Subsídios para Políticas Públicas Digitais"
  • Fonte de dados: Portal de Dados Abertos, IBGE, INMET ou Prefeituras.
  • Uso do Python: Ler planilha `.csv` e gerar 2 gráficos de tendência/distribuição.
Trilha 2 Cidadania Web

Acessibilidade e Usabilidade Web

Avaliar a acessibilidade digital em 5 a 10 sites públicos ou comunitários locais (prefeituras, escolas, postos de saúde) utilizando diretrizes internacionais da WCAG / e-MAG.

💡 Exemplo de Título para o COTB: "Diagnóstico da Acessibilidade Web em Portais Públicos Municipais do Litoral Catarinense: Uma Avaliação Baseada nas Diretrizes WCAG"
  • Fonte de dados: Auditorias automatizadas com Lighthouse, WAVE ou ASES.
  • Uso do Python: Tabular notas de contraste/acessibilidade e plotar gráfico comparativo.
Trilha 3 Pesquisa Social

Mapeamento de Dores Digitais na Comunidade

Aplicar questionário rápido (Google Forms) com moradores, comerciantes locais ou estudantes para mapear dificuldades no acesso a serviços públicos digitais ou adoção de tecnologia.

💡 Exemplo de Título para o COTB: "Mapeamento dos Desafios na Adoção de Tecnologias Digitais por Microempreendedores Locais: Um Estudo Extensionista"
  • Fonte de dados: Questionário estruturado no Google Forms (15 a 30 respondentes).
  • Uso do Python: Converter respostas da planilha em gráficos de setores e barras.
Trilha 4 Terceiro Setor

Tecnologias Abertas para ONGs e Associações

Realizar um estudo comparativo de ferramentas web gratuitas ou de código aberto (gestão de tarefas, comunicação, finanças simples) para apoiar instituições sem fins lucrativos da região.

💡 Exemplo de Título para o COTB: "Estudo Comparativo de Plataformas Web Gratuitas para Apoio à Gestão de Organizações Sem Fins Lucrativos"
  • Fonte de dados: Matriz de avaliação com critérios de usabilidade, custo e segurança.
  • Uso do Python: Gerar gráfico de radar/comparativo das pontuações das ferramentas.
Roteiro Prático 1 Abrir Overleaf

Escrita Científica em LaTeX (Modelo SBC)

A Sociedade Brasileira de Computação (SBC) e o evento Computer on the Beach (COTB) adotam o pacote oficial sbc-template.sty. Siga os passos abaixo para configurar seu artigo no Overleaf.

Passo a Passo no Overleaf

  1. Criar/Entrar na Conta: Acesse overleaf.com com seu e-mail institucional do IFSC ou Google.
  2. Criar Novo Projeto: Clique em New Project → Blank Project e nomeie como Artigo-COTB-2026-GrupoX.
  3. Subir o Pacote SBC: Faça upload dos arquivos sbc-template.sty e sbc.bst (disponíveis na aba Acervo).
  4. Configurar Autores & Afiliação: Altere os dados no código LaTeX para incluir sua dupla e os orientadores.
  5. Gerenciar Citações BibTeX: Crie o arquivo referencias.bib e adicione os blocos de citação das suas leituras.

Dicas Cruciais de Formatação

  • Citação no Texto: Use \cite{chave} para citação entre colchetes (ex: \cite{wazlawick2017}) ou \citeauthor{...} para citar o nome do autor.
  • Inserção de Gráficos: Salve seu gráfico do Python em .pdf ou .png e use \includegraphics[width=0.9\linewidth]{figura.pdf}.
  • Tabelas: Use \begin{table}[ht] com \centering e \caption{...} acima da tabela.
  • Resumo e Abstract: O modelo SBC exige Resumo em Português e Abstract em Inglês.

Roteiro Prático 2 Google Colab / VS Code

Starter Kit Python para Experimentos & Análise de Dados

Este script foi desenvolvido para ser simples, direto e 100% funcional. Ele lê um conjunto de dados, calcula estatísticas básicas e gera uma figura vetorial em alta resolução (.pdf e .png) com estilo visual moderno, pronta para ser anexada no Overleaf.

`analise_experimento.py` (Script Completo)

analise_experimento.py Python 3 
# ==============================================================================
# INICIAÇÃO CIENTÍFICA & EXTENSIONISTA — CST SISTEMAS PARA A INTERNET (IFSC)
# Script Starter Kit: Carregamento de Dados, Estatísticas e Gráfico em Alta Resolução
# ==============================================================================

import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

# 1. SIMULAÇÃO OU CARREGAMENTO DE DADOS
# Caso tenha seu arquivo CSV da pesquisa, descomente a linha abaixo:
# df = pd.read_csv("dados_coletados.csv")

# Exemplo didático: Avaliação de conformidade/tempo de 5 categorias avaliadas
categorias = ['Portal A', 'Portal B', 'Portal C', 'Portal D', 'Portal E']
pontuacoes = [88.5, 62.0, 94.0, 71.5, 83.0]
desvios    = [3.2, 5.1, 2.0, 4.3, 3.8]

# 2. TABULAÇÃO ESTATÍSTICA
media_geral = np.mean(pontuacoes)
desvio_geral = np.std(pontuacoes)
print("--- RELATÓRIO ESTATÍSTICO DO EXPERIMENTO ---")
print(f"Média Geral das Amostras: {media_geral:.2f}")
print(f"Desvio Padrão Geral:      {desvio_geral:.2f}")

# 3. GERAÇÃO DO GRÁFICO PARA O PAPER (Padrão SBC / Alta Resolução)
plt.style.use('seaborn-v0_8-whitegrid' if 'seaborn-v0_8-whitegrid' in plt.style.available else 'default')
fig, ax = plt.subplots(figsize=(7, 4.2), dpi=300)

cores = ['#16a34a', '#38bdf8', '#a855f7', '#f59e0b', '#06b6d4']
barras = ax.bar(categorias, pontuacoes, yerr=desvios, capsize=5, color=cores, alpha=0.85, edgecolor='black', linewidth=0.8)

# Linha de média de referência
ax.axhline(media_geral, color='#dc2626', linestyle='--', linewidth=1.2, label=f'Média Geral ({media_geral:.1f})')

# Rótulos de dados sobre cada barra
for barra in barras:
    yval = barra.get_height()
    ax.text(barra.get_x() + barra.get_width()/2.0, yval + 1.5, f"{yval:.1f}", ha='center', va='bottom', fontsize=9, fontweight='bold')

# Títulos e Eixos
ax.set_title('Diagnóstico Comparativo de Desempenho / Conformidade Web', fontsize=12, fontweight='bold', pad=12)
ax.set_ylabel('Pontuação Obtida (0 a 100)', fontsize=10, fontweight='bold')
ax.set_xlabel('Portais Avaliados na Região de Garopaba', fontsize=10, fontweight='bold')
ax.set_ylim(0, 110)
ax.legend(loc='upper left', frameon=True)

plt.tight_layout()

# 4. EXPORTAÇÃO AUTOMATIZADA EM PDF E PNG PARA O OVERLEAF
plt.savefig('grafico_resultado.pdf', format='pdf', bbox_inches='tight')
plt.savefig('grafico_resultado.png', format='png', dpi=300, bbox_inches='tight')
print("-> Gráficos 'grafico_resultado.pdf' e 'grafico_resultado.png' gerados com sucesso!")
plt.show()
