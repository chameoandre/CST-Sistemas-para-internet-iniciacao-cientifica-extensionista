# Workspace Directives for CST Sistemas para a Internet — Iniciação Científica e Extensionista (IFSC Garopaba)

This repository contains teaching materials, lecture slides, LaTeX source files, and activities for the **Iniciação Científica e Extensionista** course (2nd Semester / 60h total with 30h CHCE Extensão) at IFSC Câmpus Garopaba.

## Key Rules & Guidelines

1. **Compilation:**
   - Always compile LaTeX `.tex` documents using `tectonic`.
2. **GitHub Pages Deployment:**
   - All interactive lecture slides are authored in HTML5/CSS3 with Bootstrap 5 and hosted via GitHub Pages.
   - Maintain `.nojekyll` in the repository root.
3. **Docentes Responsáveis:**
   - Prof. André Moraes (`andre.moraes@ifsc.edu.br`) & Prof. Adalberto Teodosio Tabalipa (`adalberto.tabalipa@ifsc.edu.br`).
4. **Knowledge Base (`.agents/base-de-conhecimento/`):**
   - Read `.agents/base-de-conhecimento/README.md` before creating or revising course materials; it indexes the standards and lessons learned.
   - Practical guides (Roteiros Práticos) in PDF must follow `padrao-visual-roteiros-pdf.md` and start from `preambulo-roteiro-moderno.tex` (reference implementation: `2026-2/roteiro-2-python-graficos/roteiro_python_graficos.tex`).
   - Target audience may have no prior experience with the tools: explain what the tool is and where to click before the procedure.
   - When a new standard or decision is made, record it in the knowledge base and update its README index.
